# React-Native-UI-Challenge
## Halodek
An Expo + React Native app using Expo Router.

## Clone And Run

Clone the repository
```
git clone https://github.com/Bongeka-Bhungane/React-Native-UI-Challenge
cd Halodek
```
Install dependencies
```
npm install
```
run app
```
npm start
```
